# Model tables used by the age / mass solver

These are published model tables, stored unchanged (BHAC15: first six columns only). Nothing here is
fitted, smoothed or generated by AEON.

| File | Content | Source |
|---|---|---|
| `sonora_bobcat_evolution_solar.txt` | Sonora Bobcat evolution tracks, [M/H] = 0, C/O = 1.0 solar (`evolution_tables/evo_tables+0.0/nc+0.0_co1.0_mass`): mass, age, log L, Teff, log g, radius | Marley et al. 2021, ApJ 920, 85; Zenodo doi:10.5281/zenodo.5063476 (CC BY 4.0) |
| `sonora_bobcat_mags_solar.txt` | Sonora Bobcat absolute magnitudes at 10 pc, [M/H] = 0 (`photometry_tables/mag_table+0.0`), Vega system; the WISE W1-W4 columns are used | same record |
| `bhac15_tracks.txt` | BHAC15 tracks 0.01-1.4 Msun: mass, log age, Teff, log L, log g, radius | Baraffe, Homeier, Allard & Chabrier 2015, A&A 577, A42; `perso.ens-lyon.fr/isabelle.baraffe/BHAC15dir/BHAC15_tracks+structure` |

Fetched 2026-11-15. To refresh, download the files again from the sources above.
